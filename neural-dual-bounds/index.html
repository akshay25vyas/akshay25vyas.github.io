Neural Dual Bounds: Valid-by-Construction JGLP Warm-Starts for MAP and Constrained MAP

A neural network that predicts upper bounds for MAP inference, built so that every output is a valid bound. One forward pass gives a certificate that holds whatever the weights are, and it gives the classical JGLP solver a head start.

Valid by architecture
The network outputs antisymmetric edge messages on a join graph, so every output is an upper bound on the MAP value: trained, untrained or adversarial. We checked 7,990 such bounds against an exact LP solver and none fell below the optimum.
Trained without labels
For MAP inference the loss is the bound itself, through a smooth surrogate that is also a valid bound. Training needs no LP solver, no converged JGLP messages and no calibration set.
Useful where search spends its time
As a warm start it tightens JGLP's first iterations on 9 of 15 benchmark models. With test-time adaptation it gives the tightest bounds for constrained MAP on the grid and segmentation families.

A bound is only useful if it is never wrong

Many uses of probabilistic graphical models ask closely related questions again and again on one fixed graph. Branch-and-bound search expands one node per query, robustness certification verifies one input per query, constrained planning evaluates one constraint per query, and bound-based learning computes a new bound at every gradient step. Each query needs an upper bound on the MAP value, the score of the most probable assignment.

Classical dual methods such as JGLP always return a valid bound, but they often need hundreds of coordinate-descent iterations per query to make it tight. A neural network answers in a fraction of a millisecond, but a learned bound is usually valid only statistically. That is not enough. If a predicted bound falls below the true optimum on even a small fraction of queries, branch-and-bound can prune the optimal solution and a robustness certificate stops being a certificate. Conformal calibration adds a safety margin estimated on held-out data and still permits violations at its target rate. Learned search heuristics and inference networks speed up a solver or approximate its answer, but they do not certify a bound for every query.

Neural Dual Bounds removes the tradeoff by changing what the network predicts.

JGLP.
Join-graph linear programming (Ihler et al., 2012), which tightens a mini-bucket bound by shifting cost between clusters, one edge at a time.

The network predicts messages, not bounds

A mini-bucket decomposition splits the model into small clusters CαC_\alphaCα​ that overlap on shared variables. Maximizing each cluster on its own and adding the results gives an upper bound, because a sum of maxima is at least the maximum of the sum. The bound is loose when neighboring clusters prefer different values of a variable they share.

Cost shifting tightens it. A message λαβ\lambda_{\alpha\beta}λαβ​ on the separator between two clusters is added to one and subtracted from the other:

θCα(xCα,λ)=θCα(xCα)+∑β∈N(α)λαβ(xSαβ),λαβ(xS)+λβα(xS)=0  on every edge, for every xS.\begin{gathered}\theta_{C_\alpha}(x_{C_\alpha}, \lambda) = \theta_{C_\alpha}(x_{C_\alpha}) + \sum_{\beta \in N(\alpha)} \lambda_{\alpha\beta}(x_{S_{\alpha\beta}}), \\[6pt] \lambda_{\alpha\beta}(x_S) + \lambda_{\beta\alpha}(x_S) = 0 \ \text{ on every edge, for every } x_S.\end{gathered}θCα​​(xCα​​,λ)=θCα​​(xCα​​)+β∈N(α)∑​λαβ​(xSαβ​​),λαβ​(xS​)+λβα​(xS​)=0  on every edge, for every xS​.​

For any complete assignment the two contributions cancel, so the model is unchanged, but the per-cluster maxima move. The reparameterized bound is valid for every antisymmetric λ\lambdaλ:

Our network outputs one real number per edge and separator assignment, a vector m∈Redim⁡m \in \mathbb{R}^{e_{\dim}}m∈Redim​. A fixed sparse matrix AAA with entries in {−1,0,+1}\{-1, 0, +1\}{−1,0,+1}, determined by the join graph alone, writes each number into one cluster with a plus sign and into its neighbor with a minus sign, θ′=θ+Am\theta' = \theta + Amθ′=θ+Am. The antisymmetry lives in AAA, not in the weights, so training never has to enforce feasibility and nothing has to be checked afterwards. Trained, untrained and adversarial outputs all give valid bounds. Training only decides how tight they are.

Try to push the bound below the optimum

This is the worked example from the paper: four binary variables in three clusters, chained by the shared variables x1x_1x1​ and x2x_2x2​. The true optimum is 17. With no messages the bound is 19, because the clusters disagree about x1x_1x1​ and x2x_2x2​, and that disagreement is the gap of 2.

Move the four messages or scramble them. Each one is taken from one cluster and given to its neighbor. The outlined entries belong to the optimal assignment and always add up to 17, so the three maxima can never add up to less.

In the paper: Appendix A.2, Table 5. There, 2,000 message vectors drawn from a Gaussian with standard deviation 10 produced no violation and no bound below 17.

Tested against an exact solver, with inputs built to fail

The guarantee is a theorem, so a single counterexample would falsify it. We tested it where an exact reference exists. For each of 1,598 benchmark queries we computed the optimum of the join-graph dual with an independent LP solver, then bounded the query with six different message sources: no messages, the trained network, an untrained network, the trained messages negated and scaled by five, Gaussian noise at ten times the trained scale, and values of ±104\pm 10^4±104. The last three are deliberate attempts to produce an invalid bound.

All 7,990 bounds produced from a network or from noise sit strictly above the optimum. The adversarial sources are valid by a wide margin precisely because they are loose: they cannot break the bound, only waste it. The only margins that are not positive are 53 cases with no messages at all, on the three models where the mini-bucket bound coincides with the LP optimum, and they are at floating-point level.

In the paper: Appendix B.22, Table 29. The same run checks the reparameterization directly: over 153,408 random complete assignments, no total score moved by more than 2.5×10−102.5 \times 10^{-10}2.5×10−10.

Trained on the bound itself, with no labels and no solver in the loop

Because every output is feasible, the bound can be the loss. We replace the hard max with the log-sum-exp surrogate DτD_\tauDτ​, which is differentiable and, by Proposition 1, still an upper bound, and minimize it directly over sampled evidence configurations. There are no optimal messages to generate, no LP solves and no JGLP runs during training, and a single backward pass through the smooth dual gives the gradient.

Two design choices matter more than the network's size. Predicting edge messages instead of cluster tables keeps the output in the valid subspace: with edge messages the network's bound beat the mini-bucket bound on 94% of test instances, and with direct cluster-table prediction on none. Training on the bound also beat regressing onto JGLP's messages, 94% against 72% on BN_12.

Constrained MAP is the one place we use targets. There the network is supervised with LP-optimal messages for each Lagrangian, which reached comparable tightness at lower cost, and a variant trained on the smooth dual alone gave similar bound quality in a six-model pilot (Appendix B.20).

In the paper: Section 3 and Section 4.1. Training cost and the architecture and training-set sweeps are in Appendix B.27.

For MAP, the warm start buys the first iterations

We evaluate on 15 models from the UAI 2022 inference competition, covering Bayesian networks, image segmentation and grid Markov random fields, all at i-bound 4. The reference is DLPD^{\mathrm{LP}}DLP, the exact optimum of the join-graph dual solved as a linear program, because JGLP's coordinate descent can stop short of it. Every gap below is measured to that optimum.

In the paper: Section 4.1, Figure 1 and Table 1. The LP formulation is in Appendix B.1.

One instance is an illustration. For the evidence, both starts were run on the same 100 evidence seeds per model, and the comparison is paired: for each seed we take the ratio of the two dual gaps, then report its median with a bootstrap interval and a Wilcoxon signed-rank test, Holm-corrected across models.

In the paper: Appendix B.24, Tables 31 and 32. Segmentation_14's median settles at 6.3× when the seed count is raised to 1,000 (Appendix B.17).

The gain is concentrated early. Both runs descend the same convex objective, so the warm start changes the shape of the first few tens of iterations rather than the converged bound, and by iteration 500 the two agree to within a few percent. Those early iterations are what a branch-and-bound node expansion spends, and a forward pass costs a fraction of one JGLP iteration, so the prediction is recovered whenever it saves one.

Both starts are valid bounds, so a solver can also begin from whichever is lower. That gated start is never worse at iteration 0 and chose the network on 56% of instances (Appendix B.26).

For constrained MAP, adaptation wins where the problem keeps moving

Constrained MAP asks for the most probable assignment subject to budgets defined by other models on the same graph, which covers safety, fairness, adversarial and resource-constrained reasoning. Its Lagrangian relaxation is a sequence of MAP bounds: projected gradient descent on the multipliers μ≥0\mu \ge 0μ≥0, with one inner bound per step.

L(μ)=max⁡x[∑αθα(xα)−∑k=1Kμk(∑αθαk(xα)−qk)].L(\mu) = \max_x \Big[ \sum_{\alpha} \theta_\alpha(x_\alpha) - \sum_{k=1}^{K} \mu_k \Big( \sum_{\alpha} \theta^k_\alpha(x_\alpha) - q_k \Big) \Big].L(μ)=xmax​[α∑​θα​(xα​)−k=1∑K​μk​(α∑​θαk​(xα​)−qk​)].

A hundred multiplier steps means a hundred closely related queries on one graph, and with several constraints the multiplier is a vector, which earlier bounding methods for this task do not handle directly. We condition the network on μ\muμ, train it offline against LP-optimal messages for each Lagrangian, and compare four ways to start each inner solve.

Each constraint model adds Gaussian noise (σ=0.5\sigma = 0.5σ=0.5) to the original log-potentials, and its budget is the 80th percentile of its score on the test sample.

The adaptation is there for a reason. Offline training samples multipliers between 0 and 1, but gradient descent at test time is unconstrained above: 36% of single-constraint queries and 25% of two-constraint queries land beyond 1, with maxima of 36.1 and 19.4. A frozen network there predicts messages fitted to a different Lagrangian. The bound stays valid but loosens, and the replay buffer refits the network to where the trajectory has actually been.

Paired per seed, NN+TTA beats the strongest non-learned baseline on every grid and segmentation model, by a median of 1.4 to 3.7 orders of magnitude at 10 inner iterations with two constraints and 1.8 to 4.4 with one. On Bayesian networks, where successive multiplier steps have nearby optima, carrying the previous solution forward is comparable with two constraints and better by three to four orders of magnitude with one. Against plain zero-initialized JGLP, the adapted network is tighter on every non-degenerate model, by roughly an order of magnitude at 50 inner iterations on the Bayesian-network and segmentation models.

Where it helps and where it does not

The paper states the scope of its claims directly, including two negative results. So does this page.

In the paper: Section 6, Limitations and Outlook, with the supporting experiments in Appendix B.

  • One network per graph

    The MLP is tied to a join graph. A new topology, or the same graph at a different i-bound, needs retraining, so the amortization is over repeated queries on a fixed graph. A graph neural network over the join graph keeps the guarantee on graphs it has never seen, but ours was not tight on them: it improved on the mini-bucket start on 0 of 54 held-out instances. Cross-topology transfer is the main open problem.

    Section 6 and Appendix B.30

  • Early iterations only

    Both starts descend the same convex objective to the same optimum. The warm start buys the first few tens of iterations, not the converged bound, and at tight tolerances zero initialization often gets there first.

    Section 6, Tables 15 and 31

  • Nothing to gain on degenerate models

    Where the mini-bucket bound already sits at the LP optimum, as on grid10×10 and grid40×40.f2, no reparameterization can improve it and the network cannot help.

    Sections 4.1 and 6

  • Wall-clock dominance is not the claim

    Counting the one-off training, a frozen network pays for itself at a practical query count only on the four Bayesian networks, after 3,215 to 26,968 queries at a 10−210^{-2}10−2 target. Test-time adaptation costs 63 to 276 ms per step and repays that only on a large model at a loose target. The claim is bound quality at a fixed iteration budget.

    Appendix B.6, Tables 14 and 15

  • Reusing the last solution is hard to beat on Bayesian networks

    When successive multiplier steps have nearby optima, the previous step's messages are already a good start. The learned prior dominates where the trajectory drifts. Adding the two together directly was worse than either alone on all 24 benchmarks tried, although the bound stayed valid.

    Section 6 and Appendix B.23

  • More data and bigger networks do not help much

    The iteration-10 gain is already saturated with 10 training configurations. Across an 18-fold range in parameter count it varies by at most 0.385 orders of magnitude within a model, and by more than a full order between models. The network does not reach the optimal bound even on its own training instances, so the limit is the message predictor, not the data.

    Appendix B.27, Tables 35 to 39

Also in the appendix

  • Adaptation needs a trajectory. On independent MAP queries, replay-buffer adaptation gave marginal to no benefit (B.19).
  • Constrained MAP without an LP. In a six-model pilot, a pipeline trained only on the smooth dual matched or exceeded the LP-supervised one on the four non-degenerate models (B.20, B.28).
  • A root bound for search. At the root of AND/OR branch-and-bound, the forward pass was tighter than the mini-bucket bound on most queries (B.8).
  • Eleven ablations. Loss weighting, gradient steps, replay size, architecture, target type and multiplier range (B.13).
  • Seed stability. Raising five models from 100 to 1,000 seeds moved one estimate materially, Seg_14's median effect, from 8.6× to 6.3× (B.17).
  • Double precision matters. In single precision the antisymmetric cancellation carries an error of about 10−710^{-7}10−7, which dominates near convergence (B.29).
  • Not monotone in the evidence. The network predicts messages, not bound values, and its bound does not move monotonically as variables are observed (B.9).
  • Evidence encoding. One scalar per variable. One-hot encoding is the principled extension for categorical variables (B.14).
  • An adversarial image pilot. Constrained MAP on a FashionMNIST classifier ran cleanly but was degenerate, so it shows applicability, not a speedup (B.12).
  • Full benchmark suite. Forty rows, 36 distinct models, including Promedas and protein-folding networks, with per-row settings (B.2, B.10).

The construction is not specific to JGLP

Any Lagrangian dual whose decomposition passes antisymmetric messages admits the same parameterization. That includes dual decomposition, TRW-BP, weighted constraint satisfaction, and minimum-cost flow, where the LP dual already carries antisymmetric variables on edges. In each case the architecture and the self-supervised loss stay the same and only the scatter matrix AAA changes. Our experiments cover the graphical-model benchmarks above; the other settings are structural observations, not results.

In the paper: Section 6, Beyond JGLP.

Abstract

We present Neural Dual Bounds, a calibration-free framework that produces deterministic upper bounds for MAP inference in probabilistic graphical models using a single neural-network forward pass. The framework trains a network to output the edge messages of a mini-bucket style upper bound on a given join-graph decomposition in a self-supervised manner by directly minimizing a smooth dual objective. The output of this network can be used at test time to warm-start a standard JGLP optimizer. Across diverse benchmarks, this warm start yields dual gaps that are orders of magnitude tighter than those from zero initialization, with the largest gains in the early-iteration regime. We also apply our framework for the constrained MAP (CMPE) task, where neural warm starts with test-time adaptation are comparable to the adaptive baseline on Bayesian networks and achieve the tightest dual gaps, by one to two orders of magnitude, on the grid and segmentation families.
